# 苏游修改器 · 柳漪春涛正式版 v2

《苏丹的游戏》存档编辑器。**单个 HTML 文件，下载后断网可用**，不需要安装、不需要联网、不上传你的存档。

词库版本：游戏配置 `20260306160333`（卡牌 1294 · 事件 1863 · 仪式 1498 含卡位槽配置 · 标签 444 · 命运商城 50 · 成就 15）

在线使用：<https://khb10533.github.io/suyou-save-editor/>

## 功能

**卡牌 / 物品**
- 自动显示官方正确名字、称号、类型徽章与完整简介（内置 1294 张卡牌资料）
- 按分类筛选：角色 / 物品 / 苏丹卡 / 词库未收录 / 有装备的 / 有装备位的
- 按名称、ID、存在时间、堆叠数、装备数排序（只影响显示，不改动存档数组顺序）
- 搜索覆盖官方名、称号、简介、类型、ID、UID、标签、身上装备的道具名、装备位
- 按名字添加任意卡牌：输名字即可从 1294 张里挑，一键进手牌
- 变体卡（`21xxxxx`、`22xxxxx` 等）自动回退到基础 ID 取资料
- 输入序号可直接跳转并展开指定卡牌

**装备位与装备**
- 查看每张卡的全部装备位，并与官方设计对比，一键恢复官方配置
- 自由增删装备位，含 ⚔️武器 / 👗服装 / 💎饰品 / 🐎驯兽 四种，可重复添加同一种
- 已装备的道具按人物物品同样的格式展开：官方名、称号、类型徽章、简介、标签编辑
- 搜索直接给人物装上道具（任何卡牌都能放到人物身上，游戏内同样识别）
- 装备可移到手牌、复制、卸下删除；卡牌标题显示 ⚔️装备数/装备位数

**标签**
- 内置 444 条官方标签词库，含中文名、类型（增益 / 减益 / 属性）与说明
- 加标签时可搜索选择，输中文名或英文 code 都能搜到，点一下就加，不必手打
- 已添加的标签不会重复出现在候选里；词库外的自定义 code 仍可手动添加

**事件 / 仪式**
- 显示官方正确名字与类型徽章（事件表 1863 条 + 仪式表 1498 条，查不到事件时自动回退仪式表）
- **按名称添加仪式**（游戏里真正在跑的是仪式）：搜名字、地点或 ID，点一下加进存档
- 添加时**自动按官方配置补齐卡位槽数量**，并列出每个槽的官方要求（该放什么、能否留空、是否敌人位），不必进游戏反复试错
- 仪式额外显示结局 / 战斗 / 宝藏徽章与所在地点，标题栏用「槽N/官方M 已填K」标出槽位是否与官方一致，不符时一键校正
- 空槽可直接**按名字搜官方词库填卡**，不用手打 ID
- 槽位内的角色也显示官方名与称号
- 按名称、ID、存在时间、槽位数排序

**名望**
- 善名 / 恶名 / 权势 / 侠名 / 灵视 / 金骰子，直接改数值
- 每项带清零、+50；另有六项一键拉满、金骰子快捷设置
- 进阶：按 ID 或名称查改 `counter` 里的任意计数器项

**🎁 命运商城（`global.json` 独立通道）**
- 单独载入 / 下载账号全局档 `global.json`，与普通存档**完全独立**，互不影响
- 命运点：总数 / 已用 / 剩余实时计算，可直接改
- 列出全部 50 项官方加点，显示名称、说明、花费、关联卡牌、前置解锁、互斥关系、解锁条件
- 标出账号已开启 / 未开启；MOD 或新版本新增的条目标为「词库外」，同样可开关删除
- 筛选（全部 / 已开启 / 未开启 / 词库外）+ 关键词搜索
- 手动填 ID 添加未获取的加点（支持一次填多个），另有一键全开 / 全关
- 🏆 成就解锁：15 项官方成就可逐个或一键解锁 / 取消

**图鉴查询**
- 卡牌 / 事件 / 仪式三个模式，可按类型与可堆叠状态筛选
- 卡牌可一键加入手牌，任意条目可复制 ID

**其它**
- 名称词典 557 条，全局字段与标签都显示中文名，可自行增补（存 localStorage）
- 源码页可直接查看和编辑存档 JSON
- 结构自动识别，兼容不同版本存档的字段布局
- 右下角悬浮**快速翻页滑轨**：拖动定位、一键置顶 / 置底、直接跳到第一张 / 最后一张（新加的卡都在最底下）
- 改动前建议先【导出备份】

## 已知限制

- **手机版游戏没有更新联动内容**，因此联动物品即使加进存档也不会生效。
- 存档里可能存在 MOD 添加的条目（例如命运商城的一些 ID），官方配置里查不到，编辑器会标为「词库外」并原样保留，不会丢数据。

## 使用

1. 打开 `index.html`（**用 Chrome / Edge**，手机上长按文件 → 打开方式 → 浏览器）
2. 点【📂 打开存档文件】选择你的存档 JSON
3. 改完点【💾 保存并下载】，把文件放回原位置

存档位置随平台和版本而异，请自行确认后再覆盖，并**务必先备份原文件**。

## 从源码构建

仓库里的 `index.html` 就是成品，直接用即可。若要重新构建：

```bash
# 依赖
npm install tailwindcss@3.4.19

# 编译 CSS（扫描 src/ 下的 HTML 与 JS 决定产出哪些类）
npx tailwindcss -i src/input.css -o build/out.css --minify

# 组装单文件
python3 build.py
```

`src/` 下拆分为 `body.html`、`main.js`、`addons.js` 与词库 JSON；`build.py` 把 CSS、JSON5、词库和脚本内联成单个 `index.html`。
